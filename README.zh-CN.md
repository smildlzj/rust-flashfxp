## 产品介绍

Rust Flash Ftp 是一款支持中文与英语的桌面文件传输客户端，面向需要经常在本地电脑与服务器之间上传、下载和整理文件的用户。它参考经典 FlashFXP 的双栏操作方式，将本地目录、远程目录、传输队列和连接日志放在同一个工作窗口中。

从临时连接一台服务器，到维护多个项目的站点配置，再到批量传输整个目录，你可以沿用「找到文件 → 选择目标目录 → 加入队列」的操作习惯。常用服务器可以保存为站点，连接后进入预设的本地和远程目录，减少反复输入地址、账号与路径的步骤。

产品采用 Rust 实现协议、传输与本地存储，以 Tauri 2 承载桌面应用，界面使用 React 构建。当前提供 macOS Apple Silicon、macOS Intel 与 Windows x64 的自动打包配置，界面支持简体中文与 English，可在“选项 → 语言”切换。

## 适用场景

| 场景 | 使用方式 |
| --- | --- |
| 网站文件维护 | 保存网站服务器为站点，进入对应目录后上传页面、资源或配置文件 |
| 开发与测试环境传输 | 按项目组织连接，在本地工作目录与远程测试目录之间传输文件 |
| 日常服务器文件管理 | 浏览目录、下载日志或资料，完成新建目录、重命名和删除操作 |
| 批量目录上传与下载 | 将目录加入传输队列，由应用递归处理其中文件 |
| 多台服务器之间迁移文件 | 选择源站点及路径，通过本机内存中转传入当前目标站点 |
| 需要代理的网络环境 | 为站点选择 SOCKS5 或 HTTP CONNECT 代理配置 |

## 核心功能

### 双栏浏览，让文件来源和去向一目了然

本地文件与远程文件并排展示，在同一个窗口中选择源文件和目标目录。目录树用于定位文件夹，地址栏支持直接输入路径和选择历史路径，文件列表可按名称、大小或修改时间排序。

常用文件操作可以直接在列表中完成，包括新建目录、重命名、删除和传输。支持栏间拖拽与从系统拖入文件，减少来回切换窗口的步骤。队列和日志位于主窗口下方，可按需要切换显示或并排查看。

### 多种连接协议，适配不同服务器

支持 FTP、FTPS 和 SFTP，可按服务器提供的协议建立连接。FTPS 提供显式 TLS（AUTH TLS）和隐式 SSL/TLS 两种连接类型；SFTP 通过 SSH 连接，当前以用户名和密码登录为主。

临时访问可以使用快速连接栏，长期使用的服务器则保存到站点管理器。连接过程和错误信息会显示在日志中，便于查看连接、认证与传输状态。

### 站点管理，把常用连接整理好

站点管理器集中保存服务器地址、端口、协议和登录信息，并支持站点分组。你可以按项目、用途或环境组织连接，为各站点分别配置本地初始目录和远程初始目录。

- **登录方式**：保存账号密码、连接时询问密码，以及适用协议下的匿名登录。
- **临时凭证**：选择连接时询问密码时，本次输入用于当前连接，不保存到站点密码字段。
- **路径设置**：为不同项目指定各自的本地与远程工作目录。
- **兼容设置**：按站点设置字符编码和服务器时区，以适配不同服务器的目录列表。
- **连接备注**：记录站点用途，方便再次查找与辨认。

### 传输队列，持续处理上传与下载

上传和下载任务统一进入队列，支持文件与目录递归传输，并展示任务状态和传输进度。传输采用串行队列，支持取消任务及断点续传。

队列会持久化保存。重新启动应用并连接站点后，可以查看恢复出的待传任务，再点击「恢复待传」继续处理。恢复任务需要手动确认，应用不会在启动后直接重放上一次遗留的传输。

断点续传需要服务器及对应协议支持，也需要保留可继续传输的文件。对于重新发布或替换内容的文件，应先确认两端文件状态。

### 同步浏览与目录比较，辅助检查两端文件

当本地和远程采用相似的目录结构时，可以开启同步浏览，让两侧目录导航联动，减少分别寻找对应文件夹的操作。

目录比较按名称匹配当前两侧列表中的条目，标记仅在一侧存在的文件，以及同名文件的大小差异，帮助你确定需要进一步核对的内容。比较不会计算文件内容的哈希，同名且同样大小也不代表内容完全相同。开启同步浏览或执行比较不会自动删除或同步文件。

### 站点互传，减少手动下载再上传

需要把一台服务器上的文件或目录复制到另一台服务器时，可以先连接目标站点并进入目标目录，再从「站点互传」中选择源站点和源路径。

应用从源站点读取数据，经本机内存流水线传入目标站点，支持目录递归复制，中转文件不会写入本地磁盘。数据仍经过运行客户端的电脑，因此传输速度会受到本机网络以及两端服务器状态的共同影响。

这里的站点互传采用客户端中转，不使用服务器之间直接传输的 FXP 协议。

### 代理与桌面集成，融入日常使用

支持 SOCKS5 和 HTTP CONNECT 代理，可维护代理配置并在站点中选择使用。代理按站点设置，当前没有独立的全局代理开关。

系统托盘提供应用驻留入口，关闭主窗口后仍可通过托盘回到应用。窗口位置与尺寸会保存并在下次启动时恢复，常用界面选项也会保留，方便延续上一次的工作布局。

## 支持范围

当前重点是交互式文件传输与站点管理。以下边界可帮助你判断是否适合现有工作环境：

- 界面提供简体中文与 English，可在“选项 → 语言”切换并保存选择。
- SFTP 当前以密码认证为主，尚未提供独立密钥管理、Pageant 集成或客户端证书管理。
- 目录比较与同步浏览用于辅助操作，不包含自动目录同步或定时任务调度。
- macOS 和 Windows 已配置安装包构建；Linux 尚未纳入当前发布工作流。
- 当前没有与原版 FlashFXP 完全相同的功能覆盖范围，具体能力以本项目实现为准。

## 常见问题

### 应该选择 FTP、FTPS 还是 SFTP？

选择服务器实际提供的协议。SFTP 使用 SSH；FTPS 是在 FTP 上增加 TLS，两者不能互换。如果服务器同时提供多个选项，优先使用它支持的加密连接。普通 FTP 不加密传输账号密码与文件内容。

### 中文文件名显示不正常怎么办？

在站点管理器的高级设置中调整文件名编码。当前提供自动检测、UTF-8、GBK、Big5 和 Shift-JIS 等选项，实际选择应与服务器目录列表的编码一致。保存后重新连接并刷新目录。

### 为什么重启后队列没有自动开始？

这是当前的恢复方式：应用保留待传任务，由用户在确认站点和路径后手动恢复。点击「恢复待传」即可将恢复出的任务重新加入传输。

### 站点互传是否占用本机网络？

会。数据经过本机内存中转，本机同时承担从源站点读取和向目标站点发送的流量。它减少了手动下载、再上传以及本地临时文件的步骤，但不会绕过本机网络。

### 如何报告问题？

请在 [Issues](https://github.com/smildlzj/rust-flashfxp/issues) 中说明操作系统与架构、应用版本、连接协议、复现步骤，以及预期和实际结果。连接或传输问题可附上相关日志片段，界面问题可附截图。

提交前请移除密码、令牌、私钥和其他敏感信息，不要上传保存真实站点凭证的数据库文件。

## 从源码构建

需要 Rust stable、Node.js 22 和 npm，以及对应系统的桌面构建工具。macOS 需要 Xcode Command Line Tools；Windows 需要 Visual Studio C++ Build Tools 和 WebView2 运行时。

```bash
git clone https://github.com/smildlzj/rust-flashfxp.git
cd rust-flashfxp
npm --prefix ui ci
cd src-tauri
```

在 macOS 打包 DMG：

```bash
npx --no-install --prefix ../ui tauri build --ci --bundles dmg -- --locked
```

在 Windows 打包 x64 安装程序：

```bash
npx --no-install --prefix ../ui tauri build --ci --target x86_64-pc-windows-msvc --bundles nsis -- --locked
```

安装包输出在 `src-tauri/target/release/bundle/`；显式指定 `--target` 时，输出在 `src-tauri/target/<target>/release/bundle/`。
仅构建前端可在仓库根目录执行 `npm --prefix ui run build`。完整应用依赖 Tauri 原生后端，不能只用浏览器替代桌面客户端。

## 测试

在仓库根目录执行：

```bash
cargo test --lib
cargo check --manifest-path src-tauri/Cargo.toml --locked
npm --prefix ui run test
```

默认跳过依赖外部服务器的集成测试。测试环境与运行方式见 [测试规范](docs/testing.md)。

```text

```

当前桌面入口是 `src-tauri/`。根目录的 `src/main.rs`、`src/app.rs` 与 `src/app/` 保留了早期 egui 实现。

## 数据与配置

站点、代理、队列等数据保存在用户主目录的 `~/.rust-flashfxp/flashfxp.db`。数据库包含保存的凭证，密码使用固定应用密钥加密，不能替代系统密钥链；请勿将数据库提交到公开仓库或随意分享。

窗口状态等配置见 [配置说明](docs/configuration.md)。
