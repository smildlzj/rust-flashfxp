# 主题与站点常规页

用户已选择沿用 shadcn/ui，并授权直接处理。采用 Zinc 灰白色阶、低饱和蓝色、紧凑间距和轻阴影。保留已有功能及工作区未提交改动。

常规页以 FlashFXP 经典截图（https://www.hosted.com/images/kb/configure-a-site-in-flashfxp-09.png）为布局参考：站点名称、连接类型、地址/端口、登录方式/用户名/密码、远程路径、本地路径、代理、服务器时区、备注。保持中文和现代控件，不复刻 Win32 斜面。账户字段保留兼容。

路径必须持久化且连接时应用。登录方式需保存，提示密码仅用于本次连接，不落库。时区仅修正 FTP 旧 LIST 时间，MLSD/SFTP 的 UTC 时间不偏移。备注仅保存在本地。兼容旧库。

方案比较：替换 Radix Themes 改动过大；统一现有 shadcn 主题符合用户选择。更新常规页而不扩展整个密钥管理体系；新版 FlashFXP 独有的密钥管理和旧 SSL 协议并非经典截图字段。
