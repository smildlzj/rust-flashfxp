# 文件查看与编辑

Windows FlashFXP 的查看器与编辑器可独立配置，远程文件先下载到本地，再根据保存策略回传。原版入口和关联语义见[文件列表菜单](https://www.flashfxp.com/webhelp/Topics/file-list-local-browser.htm)、[文件关联](https://www.flashfxp.com/webhelp/Topics/file-associations-dialog.htm)与[查看和编辑首选项](https://www.flashfxp.com/webhelp/Topics/view-edit.htm)。

## 操作流程

- 在本地或远程列表右键选择「查看文件」或「编辑文件」，列表有焦点时也可用 Ctrl+V 或 Ctrl+E。多选时会打开其中的文件项。
- 默认使用内置 UTF-8 文本工具。「选项 → 参数选择 → 查看与编辑文件」可按文件名模式配置查看器、编辑器和远程保存策略。点击「浏览」打开系统文件选择器。macOS 选择 `.app`，Windows 选择 `.exe`。清除路径后使用内置文本工具。新规则默认用 `*` 匹配所有文件。规则使用与[模式高亮](browsing.md)相同的匹配语法。
- 内置工具直接保存本地原文件。远程编辑可设置为手动、询问或自动上传，缺省为询问。外部编辑器保存远程临时副本后，Rust 后端每 250 毫秒检查临时副本，连续两次读到相同的改动内容后执行同一策略。检测及自动上传独立于 WebView 的可见状态。主窗口日志记录回传开始、成功和失败，并显示站点与文件路径。
- 在「查看 → 活动编辑」打开或恢复独立小窗口。列表显示文件路径、站点和状态，可切换「活动编辑」或「全部编辑」，从右键菜单上传、重新打开或重新下载。重新下载须确认，下载或校验失败会保留当前编辑副本。关闭窗口隐藏列表，列表内的「关闭文件」结束单个编辑。
- 「查看与编辑文件」设置可关闭编辑时自动显示窗口，内置编辑工具仍需显示才能使用。开启「记住编辑历史」后，重新连接同一站点可从「全部编辑」恢复路径记录，重新打开时下载服务器当前版本。编辑会话和临时副本随应用退出结束。内置查看、内置编辑及远程临时副本的大小上限为 2 MiB。

## 保存与回传

文档句柄由当前 Tauri 窗口持有。打开远程文件时保存会话的站点、代理和绝对路径，回传使用这些信息建立连接。写入前重新读取源文件并比较原始内容，检测到变化时提示冲突并保留草稿。本地保存使用同目录临时文件替换。远程写入使用完整覆盖通道，FTP/FTPS 使用 STOR，SFTP 以截断模式打开目标。远程读取校验和覆盖是两次协议操作，并发修改仍可能发生在两次操作之间，覆盖中断时需复核服务器文件。
